1 Bit Camera

A palm-sized ESP32 camera that sees only in black and white, dithers each frame through a bank of 1-bit effects, and prints it as a postcard on a 57 mm thermal printer.

Role
Design & Engineering
Year
2026
Focus
Embedded · 1-bit imaging · Thermal print
Output
57 mm thermal postcards

Every pixel of every picture this camera takes is either 1 or 0, which suits thermal (receipt) paper. An ESP32-S3 board reads an OV5640 sensor, corrects the contrast of each frame, crushes it down to pure black and white and runs it through a bank of 1-bit effects (Floyd–Steinberg, Bayer, halftone, pixel and more) before sending it over Bluetooth to a 57 mm thermal printer. I designed the hardware and enclosure, wrote the firmware, tuned the dithering pipeline and built a browser simulator so you can try it out before the printer even warms up.

Point. Click. Print.

Capture a photo, apply one of 18 one-bit dither effects and print it over Bluetooth. No computer needed. Built with ESP-IDF and its esp_camera, esp_spp (Bluetooth SPP) and fatfs (SD card) components.

Hardware

BoardAi-Thinker ESP32-CAM (OV5640, 4 MB PSRAM)
CameraOV5640 5 MP, VGA (640×480), greyscale (also works with OV2640)
DisplaySSD1306 128×64 OLED, I2C (SDA=GPIO13, SCL=GPIO14)
Printer57 mm thermal, ESC/POS over Bluetooth SPP, 384 dots wide
ButtonGPIO 0 (BOOT): tap = cycle effect, hold 1 s = capture, hold 3 s = video
Dial 1GPIO 33 (ADC1): mode (threshold / size / levels)
Dial 2GPIO 2 (ADC2): value adjustment
SD cardSPI on GPIO 13–15, 2

Controls

Tap BOOTCycle to next effect
Hold 1 sCapture still + save to SD + print via Bluetooth
Hold 3 sEnter video standby
Dial 1 (GPIO 33)Select parameter: threshold / dot size / levels
Dial 2 (GPIO 2)Adjust the selected parameter

Serial console

effect N    ; select effect by number
dot N       ; dot/block size (2–16)
thresh N    ; threshold/gamma (0–255)
levels N    ; levels for comic/blocks (2–6)
invert      ; toggle output inversion
preproc     ; toggle pre-processing
video [2-60]; set frame count + capture flipbook
video       ; capture & print flipbook
go          ; capture and process
help        ; show this menu

Build the firmware (ESP-IDF)

idf.py set-target esp32
idf.py menuconfig       # check PSRAM, BT SPP, camera config
idf.py build
idf.py flash monitor

Test the effects without hardware

A host-side harness runs the same pipeline on macOS or Linux.

cc -O2 -lm -o test/test_effects test/test_effects.c main/effects.c -Imain
cd test && ./test_effects              # built-in test card
./test_effects photo.jpg halftone      # your image, specific effect
./test_effects --all                   # generate all effects from test card
